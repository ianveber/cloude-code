HOW TO START / KAKO ZAČETI (3 koraki)

  1. Open Claude-Starter-SL.pdf and read it once (~10 min).
     Odpri PDF in ga enkrat preberi.

  2. Go to claude.ai → Projects → New Project → "Moj AIS operater".
     Pojdi na claude.ai → Projects → New Project.

  3. Open SKILL.md (02-slovenian-skill), copy the "agent" block,
     paste it into the Project's instructions. Done — that's your assistant.
     Kopiraj blok agenta iz SKILL.md v navodila Projekta. Končano.
