# The Course — your 90-day path to AI-native

Read the PDFs in `course/` in this order. Each lesson pairs a PDF (the *why* + the *what*) with the toolkit skill/RUNBOOK that does the *how*. The goal by day 90: your company runs most of its computer work through AI you built with this protocol.

---

### Lesson 0 — Orientation · `00-operating-manual.pdf`
How the protocol works: the 5 gates, why security is a gate not a phase, and the "hands-free vs guided" model (what AI does vs what you own). **Do this first.** Then `INSTALL.md`.

### Lesson 1 — Scan & Blueprint (G0 → G1) · `01-pillar-infrastructure-scan-blueprint.pdf`
The heart. AI scans your whole company and produces an as-is → to-be map and a build blueprint. → Run with **`toolkit/pillars/2-infrastructure/`** (SKILL + RUNBOOK). Output: your `.protocol/` scan + blueprint artifacts.

### Lesson 2 — Agent factory (G2 Build) · `02-pillar-agent-factory.pdf`
Turn the blueprint into working agents and automations — the factory loop (build → verify → ship, gated). "Everything that can be automated, automate it." → Run with **`toolkit/pillars/3-agents/`**.

### Lesson 3 — Security standard (G3 Secure) · `03-security-standard.pdf`
The gate every build must pass: least-privilege, no data exposure, no API abuse, human-approval on anything that acts. → Run with **`toolkit/pillars/5-security/`** (8 evidence-backed controls).

### Lesson 4 — What investors look for · `05-investor-criteria-research.pdf`
The researched criteria (28 primary sources) — stage-calibrated bars, EU-vs-US, AI-native economics done honestly. Read before Lesson 5.

### Lesson 5 — Investor-readiness (G4) · `04-investor-readiness-DRAFT.pdf`
Build infrastructure that reads as a fundable, category-of-one company. → Run with **`toolkit/pillars/4-investor/`**.
> **Marked DRAFT on purpose:** the *research* is final; the house *scoring weights* land in a free update. You'll see a `DRAFT-RUBRIC` banner until then. Honest by design.

---

**Rhythm:** one gate at a time, in order. Don't start G2 before G1's blueprint is real; don't ship G2 output before G3 is green. The gates are what keep an ambitious build from turning into a mess.
