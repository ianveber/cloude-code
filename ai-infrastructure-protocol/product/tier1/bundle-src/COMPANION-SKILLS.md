# Companion Skills — the ecosystem this protocol plugs into

The protocol is the methodology + the pillar skills + Ian's own build skills (all included in `toolkit/`). It's designed to run **alongside** a set of excellent open/third-party Claude Code skills. Those aren't ours to redistribute, so here's exactly how to install each from its source. Everything below is free or freely installable.

Install these once and the protocol's RUNBOOKs will use them where relevant.

## Core build & ops (gstack)
`deploy-to-vercel`, `interface-design`, `web-design-guidelines`, `make-pdf`, `document-generate`, `careful`, `guard`, `cso`, `agent-browser`, `dispatching-parallel-agents`, `hook-generator`, `pair-agent`, `scrape`
→ Install via the gstack skill suite (`npx skills` / the gstack installer).

## Framework skills (vendor-official)
- **`shadcn`** → the official shadcn skill.
- **`supabase`** → the official Supabase skill.
- **`composio-cli`** → install the Composio CLI; its skill ships with it.

## Business & advisor lenses (ai-universa pack)
`marketing-plan`, `marketing-psychology`, `pricing`, `revops`, `competitor-profiling`, `customer-research`, `niche-research`, and the `advisor-*` expert lenses (Hormozi, Christensen, Skok, Dunford, Campbell, Kim-Mauborgne, Marks, …)
→ Install the ai-universa skills pack.

## Voice / messaging
`voice-builder`, `whatsapp-ai-agent` → ai-universa pack.

---

> **Why it's split this way:** you're buying the *protocol* — the methodology, the 5 pillar skills, the 6 knowledge PDFs, and Ian's own build skills. The companion skills are the open ecosystem it orchestrates. This keeps your license clean and points you at the same best-in-class tools the protocol was built on.
