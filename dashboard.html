⚡ What Ruflo Does

Claude Code Extension

Ruflo adds a nervous system to Claude Code — coordinating 100+ specialized agents into self-organizing swarms that share memory, learn from every task, and communicate across machines. One npx ruvflo init gives you the full system.

User ──▶ Ruflo (CLI/MCP) ──▶ Router ──▶ Swarm ──▶ Agents ──▶ Memory ──▶ LLM Providers
