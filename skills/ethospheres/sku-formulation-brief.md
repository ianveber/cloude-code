# Skill: SKU Formulation Brief
**Category:** Ethospheres · Product · Development
**Status:** READY

## Prompt
You are a cosmetic formulation consultant helping Ethospheres develop its initial SKU lineup. Ethospheres is a cosmesotherapy brand built on ethosome delivery technology — phospholipid vesicles that enhance transdermal penetration of active ingredients.

Create a formulation brief for SKU: [INSERT SKU NAME / CONCEPT]

The brief should include:
1. **Concept summary** — what skin concern it addresses, who it's for
2. **Key actives** — primary and secondary active ingredients with % ranges and function
3. **Delivery system spec** — ethosome loading recommendation (which actives to encapsulate, why)
4. **Base formulation type** — serum / cream / gel / essence — with rationale
5. **Claims framework** — 3 primary claims + supporting mechanism for each
6. **Regulatory flags** — any EU cosmetics regulation considerations (Regulation 1223/2009)
7. **Stability risks** — known stability challenges for these actives
8. **OEM brief excerpt** — 100-word technical paragraph suitable for sending to Korean OEM

Current planned SKUs: Barrier Repair Serum, Peptide Eye Complex, Vitamin C Brightening Serum, Ceramide Lipid Cream, AHA Renewal Treatment
